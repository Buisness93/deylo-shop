# NOCTÉA — Calibre N.01

Site vitrine d'une maison horlogère **fictive** : une montre modélisée entièrement en code (three.js) que l'on explore en 3D.

- **Défilement en chapitres** : ouverture, cadran, couronne, calibre (vu par le fond saphir), profil.
- **Atelier** : inspection libre (rotation, zoom), points de vue, annotations, trois finitions (or rose, acier, titane).
- Les aiguilles indiquent l'heure réelle, la trotteuse bat à 8 alternances par seconde, le balancier oscille à 4 Hz et le rotor tourne.
- Aucun modèle 3D ni image à télécharger : boîte, cadran, bracelet et mouvement sont générés au chargement.

Site statique, sans étape de build : ouvrir `index.html` via un serveur local (`python -m http.server`) ou GitHub Pages.

Marque, références et prix sont inventés. Le formulaire de rendez-vous n'envoie rien.
