# Deylo Shop — Rolex Day-Date en 3D

Fiche produit **éducative** de Deylo Shop, revendeur indépendant de montres de prestige : la Rolex Day-Date 40, explorable en 3D (three.js).

- **Défilement en chapitres** : ouverture, lunette cannelée, cadran (jour en toutes lettres, date sous la loupe Cyclope), fond Oyster vissé, bracelet Président.
- **Examen 3D** : rotation, zoom, six points de vue, rotation lente.
- **Modèle** : « Rolex Datejust » par Yevhen Artamonov (Sketchfab, CC BY 4.0), orienté automatiquement d'après son cadran ; le bracelet fermé est coupé derrière la boîte pour dégager le fond. Une reconstitution codée (Royal Oak, `js/watch.js`) reste affichée en secours si le modèle ne se charge pas.
- **Pédagogie** : histoire (boîte Oyster 1926, Datejust 1945, Day-Date 1956, calibre 3255 en 2015), chiffres du calibre, finitions à repérer.
- **Vitrine 3D** (`vitrine.html`) : autres modèles Sketchfab, avec leurs licences.

Site statique : servir le dossier (`python -m http.server`) ou via GitHub Pages.

Deylo Shop n'est pas affilié à Rolex. Rolex, Day-Date, Oyster, Président, Cyclope et le logo à couronne sont des marques de Rolex SA. La montre affichée est un modèle 3D à but éducatif, pas une photo de produit. Le formulaire n'envoie aucune donnée.
